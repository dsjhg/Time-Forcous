# Focus 沉时｜最终版需求分析

## 项目定位

本项目面向需要管理学习任务、积累专注时长并与同伴自习的学生。本次课程交付为**电脑浏览器可运行的 HTML5 网页**，不是已上线的微信小程序。用户的完整学习流程为：注册登录 → 添加任务 → 开始专注 → 完成记录 → 查看统计与打卡 → 与同伴进入同一教室。

## 功能需求与验收点

| 模块 | 需求 | 验收点 |
| --- | --- | --- |
| 账号 | 注册、登录、退出、显示账号 ID、修改昵称和密码 | 两个账号能独立使用，个人任务和手记互不泄露 |
| 计时 | 正计时/倒计时，自定义本次专注时间，暂停、恢复、放弃和完成 | 完成后保存记录；放弃不计入完成统计 |
| 环境音 | 在专注页选择白噪音，可叠加至多三种 | 可切换、暂停和调节音量 |
| 学习任务 | 设置预计专注次数和时长，编辑、删除、手动完成 | 累计完成专注达到预计时长时自动完成；延长目标可继续 |
| 重要日期 | 添加、编辑、删除个人倒计时 | 首页概览、任务页管理 |
| 统计记录 | 日、近七天、月的专注时长、次数、最长时段及任务，任务占比与时间分布 | 自然日按北京时间 0:00—24:00；近七天为连续七个自然日 |
| 打卡手记 | 自定早起截止时间；超过后记为日常打卡；月历显示种类与时间；手记按天保存 | 点击日期可查看打卡详情，能翻阅过往手记 |
| 自习室 | 创建教室、邀请码加入、成员状态、今日专注时长排名 | 两个账号接入同一后端能共享教室信息 |
| 许愿墙 | 独立发布愿望、匿名、还愿、删除、举报，带可选流星动效 | 公开内容可被其他登录用户看到，个人操作受权限限制 |

## 非功能需求和范围

页面以奶油黄、简洁卡通风格统一，学习小狗“小时”在多处提供陪伴；电脑展示布局优先，也兼容窄屏。账号、任务、专注、打卡和手记持久保存在后端 SQLite；个人数据按用户隔离。网页可本地运行，课堂演示不依赖公网部署。公开互联网服务所需的 HTTPS、长期运维和容量压测不属于本次完成范围。
