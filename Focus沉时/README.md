# Focus 沉时｜HTML5 课程设计最终网页版

Focus 沉时是一套面向学生的多人学习专注网页应用。前端使用 Vue 3 / uni-app，后端使用 Node.js 24，账号、任务、专注记录、自习室、打卡和手记保存到 SQLite。

## 课程材料

- [最终版需求分析](docs/需求分析.md)
- [最终版设计过程](docs/设计过程.md)
- `miniapp/src/`：前端页面、组件、样式与资源源码
- `server/`：后端接口、鉴权、统计和 SQLite 数据处理
- `tests/`：账号隔离、计时统计、自习室排名和任务自动完成等关键测试
- `assets/audio/`：白噪音资源、目录与来源说明

## 已完成功能

- 自主注册、登录、账号 ID 显示、昵称和密码修改
- 正计时/倒计时、自定义时长、暂停恢复、结束提醒与白噪音
- 学习任务、预计专注次数和时长、累计达标自动完成
- 日、近七天、月统计，早起/日常打卡日历及每日手记
- 重要日期倒计时、邀请码多人自习室和今日专注排名
- 独立许愿墙和学习伙伴小狗“小时”

## 从源码运行

需要 Node.js 24 和 pnpm。仓库为便于 GitHub 网页上传而只保留源码，不包含重复的 H5 构建产物；首次运行先构建网页：

```powershell
cd miniapp
pnpm install --frozen-lockfile
pnpm run build:h5
cd ..
node server/index.mjs
```

浏览器打开 http://127.0.0.1:3000/ 。SQLite 数据库会自动建立在 `data/`，该目录不会提交到仓库。两位用户要加入同一自习室，必须访问同一个后端地址。

关键回归测试：

```powershell
node --test tests/*.test.mjs
```

本次课程提交和现场检查以网页版本为准，微信小程序发布、公网部署和容量压测不在本次成果范围内。
